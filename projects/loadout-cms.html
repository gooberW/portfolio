LOADOUT CMS

LOADOUT CMS is a content management system designed to create and share game portfolios. It allows users to create and manage posts with images, videos, audio and text, with a category and notification system.

Project Page

Features

LOADOUT CMS offers a comprehensive set of features for managing and sharing game portfolios. Users can create and manage posts with various media types, including images, videos, audio, and text. The system also includes a category system for organizing content and a notification system for keeping users informed about updates and interactions.

Admins can create, update, and delete posts, manipulate user accounts, as well as manage user subscriptions and notifications. Additionally, users can also search for content, subscribe to a given category and receive notifications via email about new posts in their subscribed categories.
